System Features

Built With Cutting-Edge Tech

A complete neural-ergonomic pipeline from data collection to real-time haptic feedback.

CNN Inference Engine

Convolutional Neural Network trained on posture keypoint data for high-accuracy classification of good posture, slouching, and tech neck in real-time.

MediaPipe Pose

Real-time body landmark detection using Google's MediaPipe framework, extracting 33 skeletal keypoints per frame for precise posture analysis.

ESP32 Haptics

Wireless ESP32 microcontroller delivers instant haptic feedback through vibration motor and buzzer when poor posture is sustained beyond the threshold.

Live Telemetry

Socket.IO-powered real-time dashboard with live confidence streams, posture timeline, session analytics, and instant alert propagation.

Data Pipeline

End-to-end data collection pipeline recording posture keypoints, custom labeling tools, and automated preprocessing for model training.

Smart Alerts

Intelligent cooldown-based alert system with configurable thresholds, preventing alert fatigue while ensuring timely posture correction prompts.
